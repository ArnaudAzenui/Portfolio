Nov 2025 — present

Software Engineer, AI Benchmark Author & Reviewer, Handshake AI

Projects Dynamo & Jet · frontier-model evaluation · remote

I build and review benchmark evaluations that measure frontier AI coding agents across several concurrent programs. On Project Dynamo I write Dockerized agentic-coding tasks (Terminal-Bench 2 / Harbor): fourteen and counting, spanning ML infrastructure, off-policy evaluation, judge-bias correction, data engineering, SQL, and bioinformatics. Each ships with a deterministic verifier and seeded data generators, with reproducibility enforced through SHA-256 input pinning, and difficulty is calibrated as a statistic rather than an intuition: repeated pass@k agent trials on GitHub Actions, iterated across versions until solve rates sit inside a target band.

On Project Jet I turn real defects in open-source projects such as pdf.js, plotly.js, and seaborn into tasks, pairing behavioral fail-to-pass tests with up to 700+ pass-to-pass regression controls, all validated by an oracle/no-op reward loop in sealed CI.

I'm also the final reviewer before tasks ship: 59 evidence-backed verdicts across 61 review rounds and 14 technical domains, each reproduced by rebuilding the container and re-running verification. To keep that tractable I wrote a reusable Python tool for triaging CI artifacts, and I've used it on roughly 530 agent trials and 180 CI bundles to separate genuine failures from harness, timeout, and dependency faults. The review playbooks and shared rubric our distributed team works from are mine as well.

Unmask AI

HackUNCP 2026 · Next.js, React, Python, ML APIs · unmask-ai-rho.vercel.app

A deployed media-authentication platform that tells real photographs apart from AI-generated images. Upload a JPG, PNG, or WEBP and it runs three detection layers in parallel: metadata analysis of EXIF data, camera signatures, and timestamps; forensic inspection with error-level analysis and noise-pattern modeling; and an ensemble of trained neural classifiers that each score the image independently. The result is a 0–100 risk score with a confidence rating and a per-signal breakdown, returned in under a second, no account required. Try it live.
