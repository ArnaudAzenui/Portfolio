Nov 2025 — present

AI Research Trainer, Handshake AI

Benchmark task author & reviewer, Project Dynamo · remote

I write Dockerized agentic-coding benchmark tasks (Terminal-Bench 2 / Harbor) used to evaluate frontier LLM agents. So far that's fourteen and counting, spanning ML infrastructure, evaluation, data engineering, SQL, bioinformatics, and software engineering. Each task ships with a deterministic verifier and seeded data generators, with reproducibility enforced through SHA-256 input pinning and regeneration tests, then validated by pass@2 through pass@8 agent trials on CI.

I also peer-review other contributors' work: 59 tasks across 61 review rounds so far, which meant digging through roughly 180 CI artifact bundles and 530 agent trial trajectories to issue evidence-backed accept, revise, or reject verdicts.
